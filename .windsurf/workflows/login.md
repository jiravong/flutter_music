# Login Feature Workflow
เมื่อถูกเรียกใช้คำสั่งนี้ ให้ทำตามขั้นตอนการพัฒนาฟีเจอร์ Login สำหรับโปรเจกต์ Flutter Clean Architecture:

1. **Domain Layer:** สร้าง Entity สำหรับ User และ Auth Usecase
2. **Data Layer:** สร้าง Repository Implementation และเชื่อมต่อ API DataSource
3. **Presentation Layer:** สร้างหน้า UI และผูก Logic กับ State Management
4. **Testing:** เขียน Unit Test ก่อนจบงาน
